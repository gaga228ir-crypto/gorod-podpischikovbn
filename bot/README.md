# Бот «Город подписчиков»

## Что умеет
- **Автопроверка ника:** человек ставит код `ДОМ-1234` в описание профиля TikTok → «✅ Проверить код» → бот сам открывает профиль, видит код и выдаёт дом. Ручная проверка — запасной вариант.
- **Отписавшиеся:** в subscribers.json помечаются `~ник` — дом заброшен (тёмный, доски, «ПРОДАЁТСЯ»), бот не даёт им менять дом и забирать клад.
- **Подписчики сами** (если в .env есть TIKTOK_SESSIONID): раз в SUBS_EVERY_MIN минут бот собирает подписчиков и обновляет subscribers.json на GitHub. Кнопка в /admin — обновить сейчас.
- **Windows:** start_windows.bat добавляет бота в автозагрузку, при каждом запуске скачивает свежую версию; раз в RESTART_HOURS часов бот перезапускается за обновлением. /update — обновиться сейчас.
- `/start` — меню с картинкой, кнопка «🏙 Открыть город» (мини-приложение).
- «🏠 Мой дом» — привязка ника TikTok: проверка, что ник есть среди подписчиков, выдаёт код `ДОМ-1234` для комментариев «Почты города».
- В мини-приложении «🎨 Мой дом»: 5 вариантов бесплатно или конструктор за звёзды (оплата прямо в Telegram).
- **Клад дня**: на сайте каждый день в 00:00 МСК прячется сундук (подсказка «холодно/горячо»). Нашёл → код `КЛАД-1234` → бот даёт особый дом из конструктора бесплатно. Не больше `KLAD_LIMIT` призов в день, один в день на человека.
- `/admin` — одна панель: заявки (✅/❌), продажи, статистика. Новая заявка сразу приходит админу сообщением.

## Установка на VPS (Ubuntu)
```bash
git clone https://github.com/gaga228ir-crypto/gorod-podpischikovbn
cd gorod-podpischikovbn/bot
bash install.sh          # первый запуск создаст .env
nano .env                # заполни поля (Ctrl+O, Enter, Ctrl+X)
bash install.sh          # второй запуск — ставит и запускает бота
```
Логи: `journalctl -u gorod-bot -f` · перезапуск: `sudo systemctl restart gorod-bot`
Обновить бота: `cd gorod-podpischikovbn && git pull && sudo systemctl restart gorod-bot`

## База
По умолчанию (строки SUPABASE пустые) бот хранит всё в файле `bot/gorod.db` — VPN не нужен. Не удаляй этот файл: там заявки, особые дома и оплаты.
С `GITHUB_TOKEN` бот раз в 2 минуты выкладывает особые дома в `recipes.json` — сайт показывает их всем без VPN.

## Перед запуском
1. В Supabase → SQL Editor выполни весь `supabase.sql` (там же таблицы оплат и клада; повторный запуск безопасен).
2. В `.env`: `SUPABASE_SERVICE_KEY` — ключ **service_role** (Project Settings → API). Он секретный: только в `.env`, не на сайт и не в чат.
3. В `index.html` впиши `SUPABASE_URL` и `SUPABASE_ANON_KEY` (ключ **anon**) и `BOT_URL` — тогда сайт покажет особые дома и кнопка «Получить дом» будет вести в бота.
4. В @BotFather: `/setuserpic` → `assets/avatar.jpg`.
